# CLAUDE.md

Nuxt 4 starter template: Nuxt UI 4, Tailwind CSS 4, TypeScript (strict), pnpm. Optional features live in `layers/` (`pinia`, `i18n`, `db-postgres`, `db-sqlite`; a project keeps only the ones it needs).

Commands, conventions and layer rules are kept in one place for every project built on this template: the vault note `AI/Stack-Nuxt.md` (disk: `D:\Obsidian- VaultBrain\VaultBrain\AI\Stack-Nuxt.md`). Read it first. A project built from this template keeps only its own deviations in its CLAUDE.md and points to that note.

Template-only: `app/pages/examples/`, the `example*`/`Example*` files and `layers/*/app/pages/examples/` are demo code; the README lists every file to delete.
